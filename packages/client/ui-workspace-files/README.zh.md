# @deepseek-ai/dsh-client-ui-workspace-files

[English](README.md) | 中文

停靠在 Web GUI 右侧边缘的工作区文件浏览器。浏览器半区在 layout 拥有的 `shell.overlay` 列表槽中注册一个条目：浮动标签页打开一个可调整宽度的面板，上方是惰性文件树（带受限文本预览），下方是可拖拽分隔线分隔的"对话修改的文件"列表。节点半区只是空 loader 行。

文件树以宿主工作目录（`host.describe` 的 `cwd`）为根，每次展开通过 [`workspace-files` Remote](../../host/workspace-files/README.md) 列出一层目录：目录在前、文件在后，各自按名称排序，带字节大小；点号隐藏行由"显示隐藏文件"开关控制。已加载的列表是文件树自身的组件状态，重新打开面板不会重新拉取。非空筛选会把树切换为匹配的已加载条目的扁平列表。点击文件会打开其受限的 256 KiB UTF-8 预览（截断、二进制与业务失败均渲染为提示），"在系统中打开"动作只在页面处于 loopback 且宿主握手报告 `canOpenPath` 时把路径交给宿主原生打开器——与产物行使用的门控相同。

"对话修改的文件"列表是当前会话对话快照上的注册方私有 Reactive 派生（一个通过 inject `hooks` 舱重新发布的纯函数）：`write` 与 `edit` 调用按其 `file_path` 参数识别——绝不依赖结束语——相对目标按会话 cwd 解析，每次调用的落定状态跟踪运行中/失败，先写后编辑的同一文件只保留一行。点击一行会在树中展开其祖先目录并打开预览（定位）。未选择会话时列表显示"打开一个会话后显示其修改的文件"的空态。

面板几何（打开状态、宽度、分隔比例、隐藏开关、展开、选中、预览、筛选）是一个瞬态声明的 store——刷新后恢复为关闭，与 layout 壳的瞬态几何姿态一致。

## 模型体验

无，因为这个浏览器只是界面外壳；这里不会触达任何模型请求。

#### KV Cache 影响

无；本包既不组装也不发送提供方请求。

## 已知限制与暂缓事项

- **跨窗口保留** —— 源层为当前会话维护一张按调用键控的表：文件的事件在窗口截断或重连替换后退出窗口，条目仍保留在列表中；切换会话时表重置。跨刷新持久化的按会话索引仍留待后续。
- **相对路径是客户端最佳努力解析** —— 按会话 cwd 简单拼接；符号链接与 `..` 段不做规范化，定位可能与宿主的实际解析不一致。
- **面板内没有修改能力** —— 浏览器只列出与预览，从不调用宿主受沙箱围栏约束的 `write` Remote（留给未来的面板内编辑器）；创建目录、重命名与删除仍走 workspace 接缝。
- **筛选只覆盖已加载列表** —— 未展开的目录不会贡献匹配项；宿主侧搜索留待后续。
- **没有 mtime 列** —— `ctx.fs` 接缝只报告类型与大小。
